# 麻花的个人网站

欢迎来到麻花的个人主页！这是一个简洁而优雅的个人网站，展示我的学习过程和兴趣爱好。

## 特性

- ✨ 现代化设计，暗黑/浅色主题切换
- 🎨 流畅的动画效果
- 📱 完全响应式设计
- 🔗 社交媒体链接整合
- ⏱️ 网站运行时间实时显示

## 关于我

## 快速开始

```bash
# 克隆项目
git clone https://github.com/xiaomuahua666/nprofile.git
cd nprofile

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

在浏览器中打开 [https://mahua.uk](https://mahua.uk) 查看效果。

## 自定义配置

- 个人信息与项目 / 社交链接：编辑 `app/data.ts`
- 站点 URL：`lib/constants.ts`
- SEO 元数据：`app/layout.tsx`

## 技术栈

- **框架**: Next.js 15
- **UI 库**: React 19
- **样式**: Tailwind CSS v4
- **动画**: Motion Primitives
- **图标**: Lucide React
- **主题**: next-themes
